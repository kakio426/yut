# 윷놀이 게임 실행 방법

이 프로젝트는 정적 웹사이트이므로 별도의 복잡한 설치 과정이 필요하지 않습니다.

## 실행 방법

### 1. 파일 직접 열기
`index.html` 파일을 더블 클릭하여 웹 브라우저에서 엽니다.

### 2. 로컬 서버 실행 (권장)
오디오 파일 재생 등이 원활하지 않을 경우, 아래 명령어로 로컬 서버를 실행하세요.

**Python 사용 시:**
```bash
python -m http.server
```

**Node.js 사용 시:**
```bash
npx http-server
```

서버 실행 후 브라우저에서 `http://localhost:8000`으로 접속하세요.
